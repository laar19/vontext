Vontext — Aplicación Android para procesar videos y generar contexto para IA

## Características
- Procesamiento de videos con extracción inteligente de frames
- Transcripción con Whisper API (formato OpenAI)
- Generación de PDF profesional
- Exportación ZIP con todos los assets
- Soporte multi-video (procesar juntos o por separado)
- Persistencia en Downloads/Vontext/
- Historial de trabajos completados

## Build
```bash
./gradlew assembleDebug
./gradlew assembleRelease
```

## Instalación
```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```
